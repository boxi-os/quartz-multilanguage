Dieses Handbuch gehört zum Quartz-Plugin **quartz-multilanguage**. Und es ist mit ihm
gebaut: Der Umschalter oben rechts kommt von dort.

- <a href="{{root}}/1-einstieg/">Einstieg</a> — was Quartz allein nicht kann
- <a href="{{root}}/2-spracherkennung/">Spracherkennung</a> — woher die Sprache einer Seite kommt
- <a href="{{root}}/3-verknuepfen/">Verknüpfen</a> — wie zwei Seiten zueinander finden
- <a href="{{root}}/9-nachschlagen/">Nachschlagen</a> — alle Optionen auf einer Seite

Auch dieser Kasten steht zweimal in der Konfiguration — einmal je Sprache.
